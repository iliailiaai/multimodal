# Nemotron на фиксированных 130 задачах

Модель: `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free`.

Выборка: `data/omnigaia_fixed130/metadata.json`. Все 130 ID сверены с сохранёнными ответами Qwen; правильные и неправильные ответы включены. Ревизия медиа закреплена в `selection.json`. Ответы Qwen не передаются проверяемой модели.

Протокол: исходные промпт и три инструмента baseline, без активного восприятия. Подготовка медиа сохранена. Судья — `deepseek/deepseek-v3.2`. Температура 0.6, top_p 0.95, максимум 50 шагов и 20480 выходных токенов.

Отличия API: Nemotron не принимает `top_k` и явный `tool_choice`; эти поля опущены. Для принудительного финального ответа убирается список инструментов. Бесплатные запросы ограничены интервалом 3.1 секунды. Jina работает без ключа; Serper использует имеющиеся кредиты. Проверки до запуска записаны отдельно в `outputs/nemotron_fixed130_preflight`.

Это внутренняя выборка по завершённым задачам Qwen, а не полный OmniGAIA. Ошибки Nemotron не меняют состав выборки. Сравнивать число правильных из 130 и отдельно покрытие оценки.
