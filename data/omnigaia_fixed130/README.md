# Фиксированная выборка OmniGAIA: 130 задач

Для дальнейших сравнений использовать `metadata.json`. Состав задач закреплён в `ids.json`, контрольная сумма — в `manifest.json`.

Выбраны все 130 завершённых и оценённых задач из снимка до возобновления 27 октября 2026 года: 84 правильных, 46 неправильных. Базовый результат Qwen — **84/130 = 64,62%**. Ответы и оценки сохранены в `outputs/openrouter_qwen38_fixed130`.

Выборка не случайна: в неё вошли задачи, которые предыдущий прогон Qwen смог завершить. Это внутренний набор для сравнения моделей, а не результат на полном OmniGAIA. При дальнейших запусках не исключать неудобные задачи или ошибки; отдельно показывать покрытие и число правильных из фиксированных 130.

Пример запуска из корня репозитория (указать модель и новую папку результатов):

```bash
JINA_READER_MODE=anonymous .venv/bin/python src/run_openrouter_baseline.py \
  --input-file data/omnigaia_fixed130/metadata.json \
  --model MODEL_ID \
  --run-dir outputs/NEW_MODEL_fixed130 \
  --concurrency 4
```

Сохранять прежнюю подготовку медиа, инструменты, параметры генерации и модель-судью. Повторно использовать исходную ревизию датасета из `manifest.json`; если новый запуск обнаружит другую ревизию, сравнение требует проверки изменений медиа. Исходный результат использовал Reader с ключом; следующие запуски используют тот же Reader без ключа с ограничением скорости.
